# Deep Learning Project 

## Objective
Predict medical insurance charges using neural networks.

## Methods
- Shallow Neural Network
- Deep Neural Network
- Hyperparameter tuning with Optuna

## Results
The optimized model achieved the best performance with:
- RMSE ≈ 4729
- R² ≈ 0.86
